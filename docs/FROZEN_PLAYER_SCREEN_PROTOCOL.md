## Analysis and decisions

The primary game observation is the mean candidate game points over a complete color-swapped opening pair, in [0,1]. Count game W/D/L, margins and both color results, but infer using whole families. Resample families jointly across L and P for 10,000 bootstrap draws using a tested RNG. Report approximate Student t paired-mean intervals, one-sided .025 superiority tests for each of the two exploratory 80-ms comparisons, and bootstrap sensitivity intervals. The `.025` each controls the two primary comparisons by Bonferroni. The 300-ms, phase, indirect P/L and root analyses remain descriptive.

Also report the simultaneous one-sided bounded-score lower bounds `mean - sqrt(log(1/.025)/(2*n))`; the 64-pair radius is 0.1697626895. Clip to [0,1] only for display. Show disagreement with approximate intervals explicitly. Zero empirical variance does not establish a constant population. [statistics.mjs](../scripts/frozen-player/statistics.mjs) supplies these game primitives and tested shared resampling. Root contrasts use 10,000 whole-source stratified resamples shared across models/depths; never resample moves, siblings or frontiers independently.

Nominate a future confirmation candidate only when its 80-ms mean is at least .55 and its 300-ms mean at least .50. If both qualify, choose the larger 80-ms mean; an exact tie favors L. This nomination is a development decision. Include adverse/uncertain exact and root evidence. A separately powered, fresh confirmation is required for a convincing selected-player claim. B remains production in every outcome. No optional sample expansion or post-outcome candidate substitution.
